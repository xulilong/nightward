# 逐夜之刃 · 雾林驿道

横屏 16:9、俯视角、单人浏览器动作闯关原型。沿连续道路前进，在货车、旧桥、营地与北方灯站经历遭遇战。

## 本地运行

使用 Node.js 22.13 或更新版本。

```sh
npm install
npm run dev
```

打开开发服务器输出的地址（通常为 http://localhost:3000）。

## 操作

- WASD / 方向键：移动。默认自动瞄准附近敌人，无敌人时朝移动方向；点击鼠标攻击切换自由瞄准，Z/X 恢复自动瞄准。
- Z / 左键（可按住）：三段近战连击；命中积攒刃能。
- X / 右键（可按住）：消耗一格刃能释放穿透剑气。
- C（或空格）：闪避；Q：突进斩；E：回旋斩。
- F：救援、拾取火种、点亮营地或通关灯站。
- F：开始 / 死亡重试 / 通关后重玩；Z / X / C：选择强化。
- R（或 Esc）：暂停/继续；暂停时 F 继续，X 重新开始本关。切换窗口自动暂停。
- 顶栏支持音效开关、全屏和暂停。触屏显示方向按钮，技能点击施放并自动瞄准附近敌人。

## 试玩内容

三段连击、远程剑气、闪避和两个技能；五类敌人（含精英与 Boss）；三处强化机会，六种强化；带预警的 Boss 三种攻击与半血火区；营地检查点、死亡重试及通关结算。

检查点只在当前页面会话内保存，刷新会重新开始。画面使用 Canvas 程序绘制，分享封面为 AI 生成插画。原型美术与最终素材、平衡和完整剧情仍可继续迭代。
