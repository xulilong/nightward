# NIGHTWARD · 逐夜之刃

本地单人中世纪动作冒险。当前开放第一关「雾林边境」和第二关「灰烬村庄」。后续六关在章节目录中显示“敬请期待”，不可进入。

## 游玩

打开 http://localhost:3000/ 。服务关闭时双击「启动游戏.command」，保留终端窗口。也可使用 Node.js 22.13+ 运行：

```sh
npm install
npm run dev
```

封面“章节目录”可独立重开前两关，键盘 1 / 2 也可直接开始相应章节。F 默认继续已有存档，无存档时从第一章开始。开始独立章节会替换当前新版进度。

## 前两关的内容

**雾林边境**：沿空鞍马与血迹的线索调查失踪巡逻队，救援猎人、调查渡鸦军令、与艾琳在哨所对话，最后面对带猎犬的叛逃骑士。骑士战败后可选择留下药物放行，或交给驻军。猎人救援、骑士处理方式会写入存档。

**灰烬村庄**：独立村庄地图，包含两条纵向街道、横向连通小巷、14 栋实体房屋、谷仓、囚禁庭院与中央广场。屋顶、梁柱使用新生成的烧损木纹，村庄没有森林与旧桥。房屋遮挡玩家时淡化；建筑真实阻挡移动与投射物。救援谷仓铁匠、庭院村民、关闭粮仓火油阀，至少完成两处后可面对劫掠首领。救铁匠获得淬刃强化；保粮仓补充药剂。幸存者与任务附近火焰随救援状态变化。

两关都保留沿途遭遇、可绕行敌人、存档、重试、对话与强化。没有限时导致永久失去救援的机制，玩家可以按自己选择的顺序处理村庄目标。

## 操作与技能进度

| 按键 | 当前版本 |
| --- | --- |
| 方向键 | 移动、斜向跑动与连续转身 |
| Z | 三段剑术，可按住 |

| Q | 第二章开放破阵突进 |
| A | 有限治疗药剂 |
| F | 交互、单选对话继续、章节推进 |

X 剑气、E 回旋斩暂未在前两章开放，按规划分别在后续章节解锁。内部回归测试可以使用完整技能，以验证保留的动作实现。

右上角可静音、全屏、暂停。使用鼠标左键可自由瞄准；Z 恢复键盘自动瞄准。

## GitHub Pages（项目名 nightward）

静态版与本地版共用游戏代码，无需服务器。构建命令：

```sh
npm ci
npm run build:pages
npm run preview:pages
```

发布产物在 `dist-pages/`，可部署在 `/nightward/` 或其他子目录。图片、贴图和脚本均使用相对路径。

发布到 GitHub：
1. 创建名为 `nightward` 的仓库，将项目代码推送到 `main` 分支。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. 在 Actions 中运行 **Publish Nightward to GitHub Pages**。此后推送 `main` 会自动发布。
4. 部署完成后使用工作流给出的网址（通常为 `https://你的用户名.github.io/nightward/`）。

远程仓库：https://github.com/xulilong/nightward 。发布前需完成 GitHub 登录，并在仓库设置中启用 Pages 的 GitHub Actions 发布源。浏览器存档按网站地址隔离，线上版本不会自动读取 localhost 的进度。
